# 세준 녹음 대본 — 호커 3탄: 코피 주문법 (11/4 전달)

목표 길이 20초 안팎. 문장 사이 1초 쉬기. 휴대폰 음성메모로 녹음해서 채팅에 첨부.

1. 싱가포르 호커센터에서 그냥 "커피" 시키면, 연유 듬뿍 들어간 달달한 커피가 나와요.
2. "코피 오"는 우유 빼고 설탕만, "코피 씨"는 연유 대신 덜 단 우유예요.
3. 설탕까지 빼려면 뒤에 "코송", 얼음은 "펭".
4. 그러니까 아이스 아메리카노는 "코피 오 코송 펭". 싱가포르 가는 친구한테 보내주세요.

사실 근거: Honeycombers 'How to order kopi in Singapore' — Kopi=연유+설탕, Kopi O=블랙+설탕, Kopi C=에바밀크(무가당 연유)+설탕(가볍고 덜 닮), Kosong=설탕·우유 없음, Peng=얼음.
화면 계획: 첫 장면 세준 실사(커피 가게·컵 영상 받으면 사용) + 오로라 트래커(코피→오→씨→코송→펭) + 컵 모션그래픽(연유·설탕·얼음이 빠지고 들어감).
