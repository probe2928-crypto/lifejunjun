# 인생준준 앱 디자인 기록 (최신이 위)

월 = 일러스트·모션 · 수 = 화면 구성·타이포·읽기 흐름 · 금 = 촉감·마이크로 인터랙션·신청 동선 + 주간 정리

## 2026-11-11 (수·화면 구성·타이포·읽기 흐름) — 하늘솜
**배운 점**
- 잘 만든 체험·투어 상세(Airbnb 체험 일정, Baymard 여행 UX 조사)는 '언제·얼마나·몇 명'을 첫 화면에 한 묶음으로 보여 주고, 장소 목록은 '이름 한 줄 + 설명 한 줄'로 나눠 눈이 세로로만 내려가게 한다.
- 긴 글 사이에 사진 한 장을 숨표처럼 넣으면 '왜'에서 '무엇'으로 읽기가 자연스럽게 넘어간다. 한국어는 낱말 중간 줄바꿈만 막아도 훨씬 고급스러워 보인다.

**바꾼 것**
- `app/src/app.js`·`app.css` — 여행 상세 머리 요약을 '탑승권 꼬리표'로: 출발 후보일을 한 줄 크게(2026.11.24 → 11.27) + D-day, 아래 칸에 기간·인원(‘기내 1박’, ‘3명 모이면 출발’은 작은 둘째 줄). 이유: 3칸 상자에서 날짜·인원이 낱말 중간에 꺾이고, D-day 칩이 제목 밑에 혼자 떠 있었음.
- 같은 파일 — '이 여행에서 만나는 것'을 2×2 상자 → 번호 목록(이름 굵게, 괄호 속 설명은 아랫줄 작게). 그 위에 지금까지 안 쓰던 두 번째 사진(img2)을 숨표처럼 한 장. '하루 흐름' 안내 문구는 제목 오른쪽 → 제목 아래로.
- `app.css` — 본문·카드·FAQ에 word-break:keep-all(낱말 중간 줄바꿈 방지). trips.json·신청 폼은 그대로, 320px 폭에서도 가로 넘침 없음 확인.

**다음 회차 후보**
1. (금) 신청 완료 화면: 이륙한 비행기 → 도장 화면 연결 + 성공 햅틱 타이밍, 내 여권 빈 도장 페이지 손그림
2. (월) 탭 전환 방향감(탭 순서대로 살짝 미끄러짐), 여행 카드 배너 계절감(낙엽·눈)
3. (수) 홈 첫 화면 읽기 순서 — 히어로 글 길이 줄이고 첫 탑승권이 접히는 선 위에 보이게, 여행 카드 탭 필터·첫 카드 위계 정리

## 2026-11-09 (월·일러스트·모션) — 하늘솜
**배운 점**
- App Store '투데이' 카드·Flutter Hero 패턴: 누른 그림이 그대로 커져 다음 화면 머리가 되면 '어디서 왔는지'가 끊기지 않는다. 본문은 그림보다 살짝 늦게 올라와야 시선이 그림 → 제목 순으로 흐른다.
- 움직임은 '사용자 행동의 결과'일 때 가장 기억에 남는다(보내기를 누르면 비행기가 뜬다). 늘 움직이는 장식은 작고 느리게.

**바꾼 것**
- `app/src/app.js`·`app.css` — 탑승권 → 여행 상세 전환: 탑승권 사진이 그대로 커져 상세 머리 사진이 되고(460ms), 본문은 뒤따라 떠오름. 닫으면 사진이 원래 탑승권 자리로 되돌아감(상세를 40px 넘게 내렸거나 탑승권이 화면 밖이면 기존처럼 바로 닫힘). 이유: 화면이 '툭' 바뀌던 걸 탑승 흐름으로 이어 줌.
- `app/src/app.js`·`app.css` — 관심 신청 화면 맨 위에 새 손그림(언덕 위 활주로의 작은 비행기, 펄럭이는 바람자루, 흘러가는 구름, 빨간 지붕 관제소). '보내기'를 누르면 비행기가 활주로를 달려 이륙, 실패하면 제자리로. 이유: 글자뿐이던 신청 화면에 '떠난다'는 감정을 줌. 인라인 SVG 약 3KB.
- 움직임 줄이기 설정이면 두 움직임 모두 건너뜀. 신청 폼 필드·전송 주소·trips.json은 그대로.

**다음 회차 후보**
1. (수) 여행 상세 '하루 흐름' 읽기 흐름 — 날짜 칩·줄 간격, 스크롤 시 점선 따라 작은 비행기가 내려오는 진행 표시 검토
2. (금) 신청 완료 화면: 이륙한 비행기가 도장 화면으로 이어지는 연결 + 성공 햅틱 타이밍, 내 여권 빈 도장 페이지 손그림
3. (월) 탭 전환을 방향감 있게(왼쪽·오른쪽 탭 순서대로 살짝 미끄러짐), 여행 카드 배너 손그림에 계절감(낙엽·눈) 추가
