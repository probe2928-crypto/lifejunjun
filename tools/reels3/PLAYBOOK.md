# 인생준준 릴스 플레이북 (매일 고도화용)

매일 이 문서를 먼저 읽고 만들고, 끝나면 맨 아래 '고도화 기록'에 한 줄 추가한다.
세준 결정(2026-10-27): 기본 디자인 = **P2 시네마틱 큰자막형**, 게시 = **세준이 미리보기 보고 OK한 것만**.

## 1. 매일 순서 (수정의 수정, 검토의 검토)
1. **수치 확인** — Metricool(brand 7580610) 릴스 지표: 조회(IGRE23), 평균 시청시간(IGRE24), 3초 시청률(IGRE28), 저장(IGRE12), 공유(IGRE21). 어제 대비 무엇이 오르고 내렸는지 한 줄.
   - 홈페이지 숨김 집계: PC에서 `python v2\stats.py 7` → 인생준준(ljj)·여백의지도(yb) 일별 방문(pv)·방문자(uv)·인스타/페북 유입(sns)·신청(apply). 신청 메일은 Gmail에서 submissions@formsubmit.co 검색. 보고에 '어제 방문 N · SNS 유입 N · 신청 N' 한 줄.
2. **벤치마크 1~2개** — 잘 나가는 여행 릴스(조회 수십만+) 훅·자막·편집을 하나씩 뜯어보고 '오늘 훔칠 기술' 1개 고르기 (vidIQ 크레딧 아껴서).
3. **대본** — 아래 2장 규칙으로. 사실은 출처 확인한 것만.
4. **제작 v1** — reel3.py (P2 프리셋). 보이스 → PC에서 align.py(faster-whisper)로 단어별 시각 뽑아 자막 타이밍 맞춤 (silencedetect는 첫 구간을 잘못 잡음).
   - 자막이 말하는 내용과 화면이 어긋나면 안 됨 (예: "9시 5분" 자막에 12시 30분 시계탑 ✗).
   - 클라이맥스는 실제 장면/소리로 (위키미디어 커먼즈 CC 영상·사진, 출처는 캡션에).
   - 보간(minterpolate) 슬로모션 금지 — 유령 잔상. 느리게 보여야 하면 정지+줌.
5. **자체 검토 → v2** — 시트(7컷) 보고 고치기.
6. **독립 검토 → v3** — 제작 과정을 모르는 별도 검토자가 10개 이내 수정점 + 점수. 반영.
7. **최종 확인** — 첫 프레임, 자막 오탈자, 세이프존, 마지막 장소명, 용량(<30MB).
8. **미리보기 전송** — 세준이 OK하면 media/에 올리고 queue.json 맨 앞에 추가 → PC 작업(12:00/19:30/21:30)이 게시.
9. **기록** — 아래 '고도화 기록'에 오늘 바꾼 것 + 근거.

## 2. 대본 규칙
- 정보형은 45~60초 목표: 질문 훅(0~2초) → 통념(2~8초) → 근거 3개 → 현장 반전 → 첫 장면으로 돌아가는 끝.
- 마지막 CTA는 '보내기' 중심("이 길 같이 걸을 친구한테 보내주세요"). 모집형은 + 댓글 키워드 → DM.
- 모집 공지에는 정원(3~10명)과 "혼자 와도 돼요".
- 첫 1~2초: **숫자 + 비밀/이유 + 궁금증** ("튀르키예에선 매년 딱 하루, 9시 5분이 되면…").
- 자막 한 줄 3~15자, 말하는 속도대로 바뀜. 핵심 단어는 [노란색].
- 쉬운 이야기체(친구한테 말하듯). 은어·암호 같은 문장 금지.
- 마지막: 장소명 크게(패널 + 빨간 도시 라벨) → "가시면 ~ 꼭 찾아보세요" 같은 행동 한 줄.
- 금지: 가이드·인솔·해설, 동행비·가격 숫자, 지어낸 사실·후기.

## 3. P2 디자인 기준 (reel3 layout "full")
- 자막: BlackHanSans 104, 외곽선 9, y=0.36, 한 화면 2줄까지.
- 강조: 빨간 링 돋보기(magnify) + 빨간 라벨 / 화살표. 대상이 작을 때는 돋보기.
- 끝 카드: 장소명 124 + 빨간 라벨(도시) + 반투명 패널.
- 세이프존: 위 220px, 아래 380px, 오른쪽 140px에 글자 금지.
- 음악 볼륨 0.18, 보이스 기준 loudnorm -14 LUFS. 인코딩 crf19 / 최대 8Mbps.
- 전환: 기본 하드컷. 줌 전환(화면 전체, 0.2초)은 영상당 2~3번, 이야기가 바뀌는 컷(카운트다운 숫자, 숫자 공개)에만 + 휙 0.6·타격음 0.45. '그런데' 반전은 줌 대신 소리(음악 살짝 줄였다가 타격음).
- 자막: style "word_reveal": true + 자막마다 "wt"(단어별 시각, wordtimes.py). 띄어쓰기 기준 단어 수 = wt 개수.
- 사진만 있는 장면은 photoclip.py/band.py로 움직임, 한 컷 2초 안팎. 영상 소재가 있으면 영상 우선.

## 4. 보이스·소재 (PC 없이)
- 기본: **fetch 브랜치**에 fetch/jobs.json 푸시 → 깃허브 서버가 edge-tts 목소리(문구별 mp3)와 위키미디어 커먼즈 사진·영상을 받아 fetch/out에 커밋 → git fetch로 가져옴. 속도는 edge-tts rate로(+16~22%), atempo는 1.08 이하만.
- 문구별 mp3를 이어 붙이면 자막 타이밍이 정확히 나옴(정렬 도구 불필요).
- 1순위: vidIQ 보이스(Chris) — 크레딧 14/1000자, 11/22 갱신.
- 무료 대안: PC에서 edge-tts (ko-KR-HyunsuMultilingualNeural / InJoonNeural / SunHiNeural).
