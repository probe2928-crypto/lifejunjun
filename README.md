# 인생준준 (lifejunjun.com)

역사 테마 3인 이상 출발 동행 여행 사이트. GitHub Pages가 이 저장소의 main 브랜치를 자동 배포합니다.

- `index.html` 홈 · `run.html` RUN & TREK · `column.html` 매거진 칼럼 · `community.html` 커뮤니티
- `packages.json` 여행 상품·경비 (매일 아침 업데이트)
- `columns.json` 칼럼 (월·목 업데이트) · `posts.json` 게시판 글 (검토 후 게시)
- `races.json` RUN & TREK 해외 러닝·트레킹 대회 (매주 업데이트)
- `yeobaek/` 여백의 지도 (MARGIN ATLAS) — unseenscene.netlify.app에서 옮겨온 별도 브랜드 사이트. 게시판·저널은 yeobaek/community.json, yeobaek/journal.json. 자세한 구조는 yeobaek/README.md (전용 개인정보처리방침·runfx.js 복사본 포함, 폴더만 떼어내도 동작)
